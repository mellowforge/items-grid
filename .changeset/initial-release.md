First release: card grids that fit the screen exactly. Size presets (compact, normal, large or custom) with `maxColumns` and `maxPageSize`, fixed or measured row height, client or server paging, live or stable realtime reflow with a pending-items count, per-slot skeletons, an empty state, top or centred alignment and an optional pager — as a headless core with a vanilla mount, a React component and an Angular component. Apps get an `ItemsGridHandle` for navigation, unknown server totals are supported (`totalKnown`), PageUp/PageDown page the grid with screen-reader announcements, and invalid options throw `items-grid:` errors without changing anything.
